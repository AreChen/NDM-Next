# NDM Next plugin guides · 已安装插件

Call `ndm_list_engines` with the actual source. Read the guide for the engine you select, then use its current MCP tool schema to supply options. NDM Next lists the plugins enabled for AI below when it installs or refreshes this index.

For a new engine or an extension that shares an installed tool, start with the [plugin SDK quickstart](../sdk/quickstart.md).
