# NDM Next 0.1.2 implementation plan

## Scope

Repair media handoff, add optional in-page media controls, preserve paused progress, show completed file sizes and add elapsed time and average speed. Publish a verified Windows installer and companion extension as desktop-v0.1.2.

## Tasks

- [x] Fix media-only request replay and full response size detection in the extension. Add localized, optional in-page controls and visible popup feedback. Cover range requests, sender validation, matching, disabled controls and unsupported replay in JS tests.
- [x] Persist numeric progress snapshots with task records. Preserve old databases and recover legacy partial-file progress. Accumulate active elapsed time and received bytes across resumes; exclude paused and queued time. Cover pause, reopen, resume and unknown-length completion with local-server tests.
- [x] Use saved snapshots in the main list and compact progress window. Show actual completed file size without claiming a server-length comparison. Add compact elapsed and average-speed metrics, retaining paused percentages and connection details.
- [x] Bump desktop to 0.1.2 and companion extension to 1.1.1. Run workspace tests, extension tests, formatting, clippy, media integration and installer lifecycle checks.
- [x] Build the unsigned installer, verify metadata and checksums, upload all assets to a draft, verify the uploaded assets, then publish and synchronize main.

## Review focus

- A partial media Content-Length is never presented as the whole file size.
- Web pages cannot inject arbitrary native requests or captured credentials.
- Unknown server length stays distinct from an independently verified length.
- Reopened and restarted paused tasks retain bytes and percentages; average speed never counts saved bytes twice.
- Pauses and queue delays do not inflate active download time; old tasks show unavailable historical timing honestly.
- No native computer or browser UI review; visual acceptance remains with the user.
