## English

- Save default download options from **Settings** on supported installed plugin cards. For YouTube, you can choose a preferred video quality and how to handle playlists. Defaults apply to new downloads from the desktop app and Codex CLI. Options set for an individual download take precedence.
- Saved plugin defaults use the same local encryption as download task options. Restore a plugin's defaults from its settings panel.
- **AI integration** is now at the top of Settings. The redesigned panel shows whether AI access is enabled and whether the optional Codex CLI MCP server and Skill are installed. The panel follows the app's language and light or dark theme.

Download the Windows x64 installer, the DMG for your Mac (Apple silicon or Intel), or the Linux x64 archive. The companion browser extension is included at version 1.1.4. The release includes `SHA256SUMS` for all five downloads.

## 中文

- 在插件市场中，打开支持配置的已安装插件卡片上的 **设置**，即可保存默认下载选项。例如，YouTube 插件可以设置首选视频画质和播放列表处理方式。默认值适用于桌面端和 Codex CLI 发起的新下载，单次任务的选项优先。
- 已保存的插件默认值沿用下载任务选项的本地加密方式。可在插件设置中恢复默认值。
- **AI 集成** 已移到设置页顶部。新版面板显示 AI 接入开关和 Codex CLI 的 MCP 服务与 Skill 安装状态，并随应用切换中英文和亮暗主题。

提供 Windows x64 安装程序、适用于 Apple 芯片和 Intel 芯片的 macOS DMG、Linux x64 压缩包，以及 1.1.4 版浏览器扩展。五个下载文件均可通过 `SHA256SUMS` 校验。
