## English

- The Codex Skill now covers engine selection, task handling, and batch settings. It discovers installed plugin guides through a separate index and refreshes automatically after desktop upgrades, plugin changes, or AI access changes.
- Use `ndm_list_engines` to discover compatible engines and their options before queuing a download. Task history supports state filters and pagination. Each installed plugin has its own AI access control in the plugin market.
- Closing the main window to the tray on Windows and macOS releases its rendered content and cached task list. The scheduler and independent download windows continue handling tasks.
- Includes companion extension 1.2.1. [Plugin and AI guide](https://github.com/AreChen/NDM-Next/blob/desktop-v0.6.0/docs/plugins-and-ai.md)

## 中文

- Codex Skill 补充了引擎选择、任务管理和批量设置说明，通过索引按需读取已安装插件的指南。桌面升级、插件变动或 AI 接入设置变更后会自动刷新。
- MCP 新增 `ndm_list_engines`，可在排队前查询可用引擎和参数。任务历史支持状态筛选与分页。插件市场提供各插件的 AI 接入开关。
- Windows 和 macOS 关闭主窗口进入托盘后，释放主窗口的渲染内容和任务列表缓存。后台调度与独立下载窗口继续处理任务。
- 附带配套扩展 1.2.1。[插件与 AI 接入说明](https://github.com/AreChen/NDM-Next/blob/desktop-v0.6.0/docs/plugins-and-ai.md)
