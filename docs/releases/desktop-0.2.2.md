## English

- Made the delete confirmation window compact, with consistent top/bottom spacing and a fixed-height button row.
- Removed the small explanatory text from delete confirmation.
- The search placeholder now shows **Search** in English and **搜索** in Chinese. It updates immediately when switching languages, preserving the current query.

Windows x64 and macOS Apple Silicon / Intel packages are built by GitHub Actions. The matching browser extension remains **1.1.4**.
