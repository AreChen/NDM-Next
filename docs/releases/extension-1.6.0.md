## English

- The popup and page resources window follow the active theme in OnesDM 0.9.2 and later. They update while open and use the system theme when desktop appearance is unavailable. You can select **Follow system** under **Appearance**.

## 中文

- 弹窗和媒体资源窗口跟随 OnesDM 0.9.2 及后续版本的当前外观。窗口打开时会同步变化，无法读取桌面端外观时自动使用系统主题。「外观」设置中也可选择「跟随系统」。
