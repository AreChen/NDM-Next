## English

- Downloading tasks now keep their default violet and cyan colors in the Silver ring preset, including downloads started from AI clients. The list and progress window use the same status palette and respect saved overrides.
- OnesDM registers `com.onesdm.host` for browser integration. The `com.ndmnext.host` alias remains available until 0.9.0, and both registrations carry over authorized extension IDs.
- The companion extension 1.4.1 waits until it can read its settings before caching request headers. Download takeover and media detection have separate switches. Turning both off clears the matching cache.

**Updating**　Check for updates in **Settings → About and updates**. For an unpacked extension, use the 1.4.1 ZIP and reload it from the browser's extensions page.

## 中文

- 银环黑白主题下，「下载中」恢复默认的紫青状态色，包含 AI 发起的下载。任务列表和独立进度窗口共用状态配色，并采用用户已保存的自定义颜色。
- 浏览器集成使用 `com.onesdm.host`。旧名 `com.ndmnext.host` 兼容到 0.9.0，两套注册都会继承已有的扩展授权。
- 配套扩展 1.4.1 在成功读取设置后才会暂存请求头。下载接管和媒体识别可独立开启，两项都关闭时清空匹配缓存。

**升级**　在 **设置 → 关于与更新** 中检查更新。手动加载的扩展可用 1.4.1 ZIP 更新，在浏览器的扩展管理页重新加载。
