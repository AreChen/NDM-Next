## English

- Fixed OpenAI Codex setup on macOS when NDM Next cannot find the Codex CLI. NDM Next writes the shared user configuration for the CLI and desktop app directly and preserves other settings.
- Added MCP and Skill installation for Claude Code, Pi 0.99.0 or later, and OpenCode. Existing OpenCode JSONC and V2 configurations are supported.
- Expand **Settings → AI integration** to install, repair, or uninstall each client. Installed NDM Next Skills refresh when the app updates or plugin access changes.
- Includes companion extension 1.2.1. [AI integration guide](https://github.com/AreChen/NDM-Next/blob/desktop-v0.6.2/docs/plugins-and-ai.md)

## 中文

- 修复 macOS 上找不到 Codex CLI 时无法检查和安装集成的问题。NDM Next 直接写入 OpenAI Codex CLI 与桌面版共用的用户配置，并保留其他设置。
- 新增 Claude Code、Pi 0.99.0 及更新版本和 OpenCode 的 MCP 与 Skill 安装支持。兼容 OpenCode 现有的 JSONC 和 V2 配置。
- 展开 **设置 → AI 集成**，即可按客户端安装、修复或卸载。应用更新或插件接入状态变化时，已安装的 NDM Next Skill 会自动刷新。
- 附带配套扩展 1.2.1。[AI 集成指南](https://github.com/AreChen/NDM-Next/blob/desktop-v0.6.2/docs/plugins-and-ai.md)
