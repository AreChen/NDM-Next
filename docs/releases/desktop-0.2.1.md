## English

- Removed the animated background from download windows.
- Fixed the progress bar at 4px high when expanding or collapsing details, including compact layouts.
- Added **Copy download link** to each task's menu and the download window. The complete URL is copied, including its query parameters.
- Aligned selected menu backgrounds with hover backgrounds, using the same width and corner radius.
- Added right-side spacing to title-bar actions on macOS so the update button does not touch the window edge.

Windows x64 and macOS Apple Silicon / Intel packages are built by GitHub Actions. The matching browser extension remains **1.1.4**.

## 中文

- 移除独立下载窗口的背景动画。
- 将进度条固定为 **4px**，展开、收起详情及紧凑布局下保持一致。
- 任务更多菜单和独立窗口新增**复制下载链接**，保留完整链接及查询参数。
- 统一下拉菜单选中与悬停背景的宽度及圆角。
- 为 macOS 标题栏操作增加右侧留白，避免升级按钮紧贴窗口边缘。

Windows x64、macOS Apple Silicon／Intel 安装包由 GitHub Actions 构建；配套浏览器扩展保持 **1.1.4**。
