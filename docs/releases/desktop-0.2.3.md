## English

- Refined the main toolbar, resizable sidebar and settings cards, with smoother theme, language and control transitions.
- Made the download progress window more compact, with clearer metrics and quick actions for copying, opening, proxy selection and deleting a task.
- Added a redownload action and improved deletion of records whose files are already missing.
- Improved window dragging, startup registration and the delete confirmation layout.

Windows x64 and macOS Apple Silicon / Intel installers and the companion extension are built by GitHub Actions. The extension version is **1.1.4**.

## 中文

- 优化主窗口工具栏、可调整宽度的侧边栏和设置卡片，加入更柔和的主题、语言及控件过渡。
- 精简独立下载窗口，优化进度数据，并提供复制、打开、代理和删除等快捷操作。
- 增加再次下载功能，修复文件已不存在时无法删除任务记录的问题。
- 改进窗口拖动、开机启动注册和删除确认窗口布局。

Windows x64、macOS Apple Silicon／Intel 安装包及配套扩展由 GitHub Actions 构建。扩展版本为 **1.1.4**。
