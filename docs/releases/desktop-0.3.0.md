## English

- Browse, search and manage add-ons in Plugin market. Cards follow the app language and show the plugin category, version and installation status. Search matches English and Chinese terms, and the category and installed filters can be combined.
- Install the official YouTube and BitTorrent plugins on demand, or import a compatible ZIP. The download engine SDK includes a package contract, native form controls and a guide to localization. Plugin engines exit when their downloads finish.
- Install the optional Codex CLI MCP server and Skill from Settings. When AI access is enabled, installed plugins expose their download tools automatically. Codex can use the default download folder and configure task and thread limits for a batch or for the app.
- Run NDM Next on Linux x64, with support for X11 and Wayland.

Install the Windows x64 setup, open the DMG for your Mac, or unpack the Linux x64 archive. This desktop release includes the matching companion browser extension ZIP.

## 中文

- 在插件市场浏览、搜索和管理插件。卡片随应用语言切换，显示分类、版本和安装状态。搜索同时匹配中英文，可叠加分类和「仅已安装」筛选。
- 按需安装官方 YouTube 或 BitTorrent 插件，也可导入兼容的 ZIP。下载引擎 SDK 提供包格式、原生表单控件和多语言开发指南。插件引擎在下载结束后退出。
- 在设置中按需安装 Codex CLI 的 MCP 和 Skill。开启 AI 接入后，已安装插件的下载工具会自动可用。Codex 可以使用默认下载目录，并为单个批次或应用全局设置任务数和线程数。
- 新增 Linux x64 支持，可在 X11 和 Wayland 下运行。

Windows 用户运行 x64 安装程序，macOS 用户打开对应架构的 DMG，Linux 用户解压 x64 安装包。本版本附带对应的浏览器扩展 ZIP。
