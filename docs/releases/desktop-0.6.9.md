## English

**Upgrade notice** This transition release recognizes the lowercase repository address. GitHub now returns `AreChen/OnesDM`, so 0.6.9 users need to install 0.7.1 or later manually once. [Download and installation instructions](https://github.com/AreChen/OnesDM/releases/tag/desktop-v0.7.1)

Segmented HTTP downloads now handle rotating CDN signatures while validating the resource path, strong ETag and exact byte ranges.

## 中文

**升级提示**　此过渡版识别全小写的仓库名。GitHub 现在返回 `AreChen/OnesDM`，请从 0.6.9 手动安装一次 0.7.1 或更新版本。[下载与安装说明](https://github.com/AreChen/OnesDM/releases/tag/desktop-v0.7.1)

HTTP 分段下载支持 CDN 签名轮换，同时继续校验资源路径、强 ETag 和精确字节范围。
