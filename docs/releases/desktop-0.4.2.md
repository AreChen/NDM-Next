## English

- Plugin tasks show the resolved title in the task list and progress window. The progress window shows when the plugin is finalizing media and distinguishes media processing errors from network errors.
- The plugin settings page places the plugin name below **Back to market**.
- Plugin switches and short lists of choices use the same sliding selection as the theme setting. YouTube uses it for playlist and subtitle choices in plugin settings and New download, and for the independent proxy switch in plugin settings.
- Update the YouTube plugin to **0.1.2** in Plugin market. The update merges separate video and audio tracks into MKV, which the FFmpeg bundled on Windows and macOS supports. It adds uploaded and automatic subtitles with language selection, plus a separate proxy switch and URL in the YouTube settings.

This release includes the Windows x64 installer, Apple silicon and Intel macOS DMGs, the Linux x64 archive and the 1.1.4 companion browser extension. Verify the downloads with `SHA256SUMS`.

## 中文

- 插件解析到视频标题后，任务列表和进度窗口会显示该标题。进度窗口会显示封装状态，并区分媒体合并失败与网络错误。
- 插件设置页把插件名称放在 **返回市场** 按钮下方。
- 插件的开关和简短选项沿用主题切换的滑动分段控件。YouTube 的播放列表和字幕可在插件设置和新建下载中切换，独立代理开关位于插件设置。
- 在插件市场将 YouTube 插件更新至 **0.1.2**。独立下载的音视频轨道现在合并为 MKV，兼容 Windows 和 macOS 随包提供的 FFmpeg。字幕支持作者上传和自动字幕，可指定语言。YouTube 设置页也新增了独立代理开关和地址。

提供 Windows x64 安装程序、适用于 Apple 芯片和 Intel 芯片的 macOS DMG、Linux x64 压缩包，以及 1.1.4 版浏览器扩展。下载校验值见 `SHA256SUMS`。
