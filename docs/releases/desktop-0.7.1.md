## English

The desktop updater now recognizes the official GitHub repository regardless of how its owner or name is capitalized. Future changes such as `onesdm` → `OnesDM` no longer interrupt update discovery. The updater still verifies the download origin, exact release tag and filename, package size, and SHA-256.

**Upgrading from 0.6.8, 0.6.9 or 0.7.0** Install 0.7.1 manually once. These older versions skip installers at the current GitHub address. Finish or pause your downloads and quit the app completely. Keep your existing profile to retain download records, settings and plugins.

- **Windows x64** — Run `OnesDM.exe` over the existing installation.
- **macOS** — Open the DMG for your Mac (`arm64` for Apple Silicon, `x64` for Intel). Drag OnesDM into Applications, replace the existing copy and open it.
- **Linux x64** — Extract the archive into a new folder and launch `ndm-desktop` there.

## 中文

桌面更新器现在能识别官方 GitHub 仓库所有者和仓库名的大小写变化。以后即使再将 `onesdm` 调整为 `OnesDM`，应用也能发现新版本。更新器继续严格核对下载来源、版本标签、文件名、包大小和 SHA-256。

**从 0.6.8、0.6.9 或 0.7.0 升级**　这些旧版会跳过当前 GitHub 地址下的安装包，请手动安装一次 0.7.1。先暂停或完成下载，再完全退出旧版。保留原用户数据即可继续使用下载记录、设置和插件。

- **Windows x64** — 运行 `OnesDM.exe` 覆盖安装。
- **macOS** — Apple 芯片选择 `arm64`，Intel 芯片选择 `x64`。打开对应 DMG，将 OnesDM 拖入「应用程序」，替换并打开。
- **Linux x64** — 将压缩包解压到新目录，运行其中的 `ndm-desktop`。
