## English

- Page parsing actions span the same width as the surrounding controls in the popup and resource window. Plugin versions appear on the right.
- The resource window uses a compact header with the page title and refresh control.

Unpack the ZIP and load it in Chrome or Edge. For an existing unpacked copy, replace its files and reload it. [Installation guide](https://github.com/AreChen/NDM-Next/blob/extension-v1.2.1/docs/extension-install.md)

## 简体中文

- 扩展主面板和网页资源窗口的插件解析入口与相邻控件等宽，插件版本号统一靠右。
- 网页资源窗口使用更紧凑的内容标题区，保留来源标题和刷新按钮。

解压 ZIP 后可在 Chrome 或 Edge 中加载。已安装解压版的用户可覆盖原目录后重新加载。[安装指南](https://github.com/AreChen/NDM-Next/blob/extension-v1.2.1/docs/extension-install.md)
