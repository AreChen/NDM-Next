## English

- Choose **Upgrade** on macOS to verify the downloaded disk image, wait for active downloads to finish, replace the application in its current location, and reopen it. Download records and settings stay in their existing folders. When the application folder requires manual installation, NDM Next opens the verified DMG.
- Install 0.5.1 once from the DMG to enable in-app installation for later upgrades. Choose the Apple silicon or Intel DMG for your Mac.
- GitHub Actions tests and packages the companion extension on extension changes and desktop releases. The release includes the extension 1.2.0 ZIP and its checksum. [Extension installation guide](https://github.com/AreChen/NDM-Next/blob/desktop-v0.5.1/docs/extension-install.md)

Run the Windows x64 installer. On Linux x64, install the runtime dependencies, extract the archive, and run `./ndm-desktop`. [Linux installation guide](https://github.com/AreChen/NDM-Next/blob/desktop-v0.5.1/desktop/packaging/linux/README.md)

## 中文

- macOS 支持应用内升级。点击 **升级** 后会校验下载的磁盘镜像，等待正在运行的下载结束，再原位替换应用并重新打开。下载记录和设置保存在原有目录。安装目录需要手动安装时，会打开已校验的 DMG。
- 先用对应 Apple 芯片或 Intel 版 DMG 安装一次 0.5.1，之后即可在应用内直接升级。
- GitHub Actions 会在扩展变更和桌面发布时自动测试、打包扩展。本次发布包含扩展 1.2.0 的 ZIP 和校验值。[扩展安装指南](https://github.com/AreChen/NDM-Next/blob/desktop-v0.5.1/docs/extension-install.md)

Windows x64 直接运行安装程序。Linux x64 安装运行依赖后解压，运行 `./ndm-desktop`。[Linux 安装指南](https://github.com/AreChen/NDM-Next/blob/desktop-v0.5.1/desktop/packaging/linux/README.md)
