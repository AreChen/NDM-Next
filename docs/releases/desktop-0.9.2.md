## English

- Browser Extension 1.6.0 follows OnesDM’s active light or dark mode and preset or custom colors in the popup and page resources window. Choose **Follow system** in the extension’s appearance settings to use the system theme.
- The desktop sends appearance changes to open extension windows as they happen. If the desktop is closed or the native host is unavailable or too old, the extension uses the system theme.

## 中文

- 浏览器扩展 1.6.0 的弹窗和媒体资源窗口默认跟随 OnesDM 桌面端当前的亮暗模式、预设配色和自定义配色。可在扩展的外观设置中改为「跟随系统」。
- 打开的扩展窗口会收到桌面端推送的外观变化。桌面端退出、原生宿主不可用或版本较旧时，扩展自动使用系统主题。
