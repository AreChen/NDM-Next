## English

Personalize OnesDM in **Settings → Appearance and language → Color palette → Custom**.

- Pick a theme color from the visual color picker. The secondary color and surface color follow it automatically until you set them individually.
- Use the **Download statuses** tab to set colors for completed, failed, paused, active and queued downloads. The same colors appear in the download list and progress windows.
- Click a swatch to preview the color and choose **Apply** to save it. Selecting a preset hides the editor. Saved download status colors apply across presets.

**Updating**　Use **Settings → About and updates → Check for updates** from 0.7.1 or later. If you use 0.6.8, 0.6.9 or 0.7.0, finish or pause transfers, quit the app and install 0.8.1 manually once. Keep your existing profile to carry over download history, preferences and plugins.

## 中文

在 **设置 → 外观与语言 → 界面配色 → 自定义** 中调整 OnesDM 的颜色。

- 用可视化色盘选主题色。辅助色和界面底色会自动搭配，也可以分别调整。
- 在 **下载状态** 页签中设置完成、失败、暂停、下载中和等待的颜色。主列表和独立进度窗口共用这些配色。
- 点击色块即可预览，点击 **应用** 保存。切回预设时收起编辑区，已保存的下载状态色适用于各套预设。

**升级**　0.7.1 及以上版本可在 **设置 → 关于与更新 → 检查更新** 中升级。使用 0.6.8、0.6.9 或 0.7.0 的用户请先暂停或完成下载，完全退出后手动安装一次 0.8.1。保留原用户数据即可带上下载记录、偏好和插件。
