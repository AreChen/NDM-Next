## English

OnesDM now speaks the same nine languages as its website. Choose English, Simplified Chinese, Traditional Chinese, Japanese, Korean, Spanish, Brazilian Portuguese, French or German in **Settings → Appearance and language**. New profiles use the first supported system language. An upgrade keeps your saved language.

- The download list, progress windows, tray menus, settings, built-in plugin labels and the Windows installer are localized. OnesDM MCP can read and change the interface language.
- The companion browser extension 1.4.0 follows the browser language or lets you choose independently. Each desktop release includes the matching extension ZIP.
- All nine READMEs include a new download banner, a plugin diagram and original light and dark screenshots. The app header and browser extension now use a light version of the silver-ring icon on light backgrounds.

**Updating**　In 0.7.1, use **Settings → About and updates → Check for updates**. From 0.6.8, 0.6.9 or 0.7.0, pause or finish transfers, quit the app and install 0.8.0 manually once. Keep your profile to retain download history, preferences and plugins.

[Download for Windows, macOS and Linux](https://github.com/AreChen/OnesDM/releases/tag/desktop-v0.8.0) · [Read the guide](https://github.com/AreChen/OnesDM/blob/desktop-v0.8.0/README.md)

## 中文

OnesDM 的界面语言现已与官网对齐。在 **设置 → 外观与语言** 中可以选择英语、简体中文、繁体中文、日语、韩语、西班牙语、巴西葡萄牙语、法语和德语。首次启动会匹配系统偏好语言，升级会保留原来的选择。

- 下载列表、独立进度窗口、托盘菜单、设置、内置插件标签和 Windows 安装程序均已支持九种语言。也可以通过 OnesDM MCP 查询或修改界面语言。
- 配套的浏览器扩展 1.4.0 可以跟随浏览器语言，也可以单独设置。对应的扩展 ZIP 随桌面版一同发布。
- 九份 README 换上下载主题头图、插件示意图以及深浅两套真实软件截图。桌面标题栏和浏览器扩展会随浅色主题切换为浅底银环图标。

**升级**　0.7.1 用户可在 **设置 → 关于与更新 → 检查更新** 中升级。使用 0.6.8、0.6.9 或 0.7.0 的用户请先暂停或完成下载，完全退出应用，再手动安装一次 0.8.0。保留原用户数据即可继续使用下载记录、偏好和插件。

[下载 Windows、macOS 或 Linux 版](https://github.com/AreChen/OnesDM/releases/tag/desktop-v0.8.0) · [阅读中文说明](https://github.com/AreChen/OnesDM/blob/desktop-v0.8.0/README.zh-CN.md)
