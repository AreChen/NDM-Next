## English

- Probe public pages for HLS and DASH URLs over HTTP. Start a native media download with a mobile User-Agent preset, custom User-Agent, Referer or request language from MCP or the CLI. For streams loaded by page scripts, capture the stream with the companion extension.
- OnesDM Skill routes requested downloads through the MCP server or CLI and explains how to discover installed plugin capabilities and verify task results.
- Download Characters saves reusable engine, device, network and destination preferences as local Skills. Roles survive plugin upgrades and reinstallations and can be selected for individual downloads.
- AI clients can configure the TUN DIRECT port, appearance and download status colors, proxy, cache folder, startup and sidebar through the desktop settings tools.
- The desktop migrates authorized browser extension IDs to `com.onesdm.host` and retires the legacy host registration. Update the companion extension to 1.5.0 for the current host name.

## 中文

- 通过 HTTP 从公开页面识别 HLS 和 DASH 流地址。MCP 和 CLI 可指定手机 UA、任意自定义 UA、Referer 和请求语言，交由桌面端下载和封装。由网页脚本加载的流可以用配套扩展捕获。
- OnesDM Skill 引导 AI 优先把用户发起的下载提交到 MCP 或 CLI，查找已安装插件的能力，并用任务 ID 确认结果。
- 下载角色将引擎、设备、网络和保存位置等偏好保存为本地 Skill。角色可单独用于任务，插件升级和重装时会保留。
- AI 可通过设置工具调整 TUN DIRECT 端口、主题和任务状态色、代理、缓存目录、开机启动及侧边栏。
- 桌面端迁移已授权的扩展 ID 到 `com.onesdm.host` 并移除旧宿主注册。配套扩展可更新到 1.5.0。
