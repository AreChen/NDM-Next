## English

- Bring the standalone progress window forward when NDM Next takes over a browser download on macOS. During a browser-triggered cold start, the main window stays hidden.
- Match the Windows title bar layout on macOS. The main and progress windows now place minimize, maximize or restore, and close on the right. The delete confirmation shows only a close button.

Install the Windows x64 setup or open the macOS DMG for your Mac's architecture and drag NDM Next to Applications. This release also includes the companion browser extension **1.1.4** ZIP.

## 中文

- 修复 macOS 接管浏览器下载后独立进度窗口留在后台的问题。由浏览器冷启动时，主窗口保持隐藏。
- macOS 标题栏与 Windows 布局统一。主窗口和进度窗口的最小化、最大化／还原和关闭按钮位于右上角，删除确认窗口仅显示关闭按钮。

Windows 用户运行 x64 安装程序。macOS 用户打开对应架构的 DMG，并将 NDM Next 拖入「应用程序」。本版本附带浏览器扩展 **1.1.4** ZIP。
