## English

- On Windows, opening a file or folder now lets the app finish handling the click before invoking the Windows Shell. This prevents a potential crash if the Shell dispatches window messages while launching the default player or File Explorer.
- This release includes companion extension 1.2.1. [Extension installation guide](https://github.com/AreChen/NDM-Next/blob/desktop-v0.5.2/docs/extension-install.md)

## 中文

- 在 Windows 上，打开文件或文件夹时，应用会先完成点击回调，再调用系统 Shell，避免默认播放器或文件资源管理器启动期间派发窗口消息时可能引发的崩溃。
- 本次发布附带配套扩展 1.2.1。[扩展安装指南](https://github.com/AreChen/NDM-Next/blob/desktop-v0.5.2/docs/extension-install.md)
