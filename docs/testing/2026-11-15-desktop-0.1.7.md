# Desktop 0.1.7 verification

## Storage behavior

Settings has a compact, collapsible **Storage and cache** group with folder pickers, reset buttons, retention days, usage statistics and manual cleanup. Defaults use Windows `FOLDERID_Downloads`, including redirected locations, and `%LOCALAPPDATA%\NDM Next\Cache`. A saved custom download path is preserved; the old automatic `%USERPROFILE%\Downloads` default migrates to the known folder. The native host reads updated preferences for each request and preserves the destination of an existing handoff when it is retried.

New desktop tasks use `transfers` under the chosen cache root. Each task's workspace is persisted separately from its immutable download request. Existing legacy partial files and previously assigned workspaces remain in place when settings change. SQLite schema 2 migrates to 3; earlier app versions reject schema 3 rather than silently reading an unsupported profile.

Cleanup inventories only registered task directories and recognized temporary files. Prepared, queued, running, paused and failed tasks remain protected. Unexpected entries and links are skipped. Completed output files are not part of this inventory. Orphaned workspaces remain discoverable after removing a task record. Update downloads now use the configurable cache root; old update roots remain discoverable and an updater lease protects downloaded or pending installers. Automatic cleanup defaults to seven days, checks every six hours, and can be disabled with a zero-day setting.

Saving across volumes first copies the completed file into an owned temporary file on the destination volume, then publishes it without overwriting an existing file. Copy progress has a separate Saving phase. Cancellation removes the destination temporary file and preserves the source for retry.

- Scheduler regression verifies real HTTP download, pause, cache-root change, cleanup protection, resume and the workspace assigned to a later task.
- Two tests additionally passed with destination fixtures on **E:** and cache/source on **C:**, confirmed as separate volumes: atomic publication without overwrite, and the full scheduler download/pause/resume/save path. These repeat two of the 221 tests under actual cross-volume conditions.
- Formatting, whitespace checks and all-target clippy with warnings denied passed.
- Release compilation and third-party license checks passed. Installer, desktop and native host product versions are **0.1.7**. All **18** companion ZIP files match extension source bytes.
- Isolated installer lifecycle fixtures passed launch, guard handling, registered custom-path shutdown, replacement, data preservation and uninstall.
