# Desktop 0.2.1 validation

## Local checks

- Rust 1.100.0, Windows x64: default workspace tests **225 passed / 15 ignored**, no failures. Ignored media-tool/network/subprocess cases are not counted as verified.
- The headless layout regression reproduced a **3px** progress track under compact layout pressure before the fix. It now stays **4px** across compact → expanded → compact layouts.
- The headless copy-button test verifies the entire URL is copied, including percent encoding, query parameters and fragment. Task menus and download windows share the clipboard implementation.
- Extension tests: **79 passed**. Workspace Clippy with `-D warnings`, formatting and Git whitespace checks pass. DESIGN.md lint reports **0 errors / 0 warnings**.
- The background layer and its `Ambient` motion state have been removed. Finite progress/sidebar/page transitions remain; no CPU/GPU benchmark is claimed.
- Inspection of Kit 0.10 confirms menu hover is painted on the padded outer row. Choice backgrounds now extend over that same row, with the same corner radius. macOS title-bar actions retain **12px** of trailing space.

## Visual acceptance

The user performs visual review. Headless tests do not operate the user's application windows. Actual appearance, macOS title-bar spacing and platform scaling still need user review.

## Release checks

The release pipeline must build Windows x64 and macOS arm64/x64, validate licenses, and pass default workspace and extension tests before publishing. Public release files are checked against GitHub digests and CI artifacts after publication. The opt-in updater check downloads and verifies the installer without executing it.
