# Desktop 0.2.0 validation

## Local checks

- Rust 1.100.0, Windows x64: workspace tests **224 passed**, 15 ignored (media-tool/network/subprocess fixture gates); no failures. Ignored cases are not counted as verified.
- Desktop regression coverage includes forward/reverse range selection in filtered/reordered lists, missing anchors, interrupted motion continuity, reduced-motion settling and bounded/disabled ambient effects.
- GPUI headless input tests cover neutral initial focus, explicit input focus and blur on outside clicks. The shared task action group is tested to prevent file/action clicks from toggling row selection. These tests do not operate the user's application windows.
- Extension tests: **79 passed**.
- Workspace Clippy with `-D warnings`, formatting and Git whitespace checks pass.
- `cargo tree -i gpui-pre` confirms a single **0.3.12** backend shared by Kit **0.10.0** and the Kit motion adapter.
- Vendored adapter: all 14 source files match published **gpui-motion-kit 0.5.0** byte for byte; both original license files are retained. Only its dependency manifest targets the newer Kit.
- AGENTS.md mechanical validation passes. DESIGN.md CLI 0.4.0 reports **0 errors / 0 warnings**.

## Visual acceptance

The user performs visual review. No browser/computer automation or screenshot-based claim of visual acceptance was made. Windows/macOS scaling, actual hover feel and appearance still need user review.

Finite sidebar/page/progress transitions use the Kit scheduler and stop when settled. The ambient layer adds one translucent gradient, uses existing progress refreshes and does not own a timer. It is absent when inactive, hidden, paused, completed or reduced motion is enabled. This is an implementation bound, not a measured CPU/GPU benchmark.
