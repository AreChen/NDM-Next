# Desktop 0.1.4 validation

## Changes

- The independent progress window starts polling queued tasks and existing workers even if its subscription missed `Started`. A temporary absence of a worker no longer ends tracking for a queued/running task. Polling reconciles terminal state and retains saved bytes; terminal windows stop polling.
- Media controls prefer the space above the player, with a viewport-clamped fallback near its upper edge. A manual, non-modal popover puts the host in the browser top layer where supported. Both the host and its transparent backdrop let unrelated pointer events through. Fullscreen/popover changes restore its layer; older browsers retain the fixed-position fallback. Frame boundaries, conservative source matching and opaque capture-ID replay are preserved.
- Configured proxies remain encrypted and disabled by default, including preferences upgraded from older versions. The explicit default toggle controls scheduler defaults, media inspection and update requests. Without that opt-in, system network settings apply.
- The lightning button safely pauses and restarts only its HTTP(S), HLS or DASH task through the saved proxy. Its encrypted override survives pause/resume and application restart. Protocol selections, request headers, explicit limits and cumulative transfer statistics are preserved. An installer reservation rejects the change atomically. Unsupported protocols are not offered this HTTP proxy button.
- Queued worker dispatch revalidates state/options under the worker lock; pausing a queued task uses the same lock. Proxy options and requeue admission are committed in one database transaction.
- Only the additional lightning SVG is embedded, alongside the existing component icon set. Release checklist requires matching English and Simplified Chinese notes.

## Verification

- Rust 1.100.0 local workspace: **204 passed**, including audited FFmpeg media integration. Explicit public-network smoke tests and the two subprocess fixture entry points are excluded from that count.
- Extension **1.1.2**: **70 passed**, including above-player placement, viewport bounds, top-layer lifecycle, transparent click-through host/backdrop, API fallback, capture-ID-only requests and immediate disable/domain blocking.
- Local HTTP/proxy integration confirms authenticated per-task routing, unchanged request credentials, retained statistics, proxy persistence across scheduler restart, byte-correct output and isolation from other tasks. Additional checks cover installer admission, proxy opt-in/legacy preferences, HLS/DASH track selections, explicit HTTP detection, queue tracking and the embedded lightning asset.
- Formatting and all-target clippy with warnings denied passed.
- Installer lifecycle fixtures passed launch, guard handling, registered custom-path shutdown, replacement, data preservation and uninstall in an isolated temporary profile. Installer and both executable product versions are 0.1.4. All fourteen companion ZIP files match source byte for byte.

No native-app or browser UI automation is used. Visual acceptance remains with the user; these checks do not alter the live installation or its task data.
