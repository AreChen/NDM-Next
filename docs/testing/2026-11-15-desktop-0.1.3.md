# Desktop 0.1.3 validation

## Fixes

- Notices now expire after five seconds, can be dismissed, and clear on section/language changes. A single cancellable timer replaces earlier timers, including repeated identical messages.
- The delete confirmation previously left `delete_dialog` populated after its window closed. Update admission therefore returned silently forever. Closing the dialog now clears the matching handle; update admission also rejects stale handles as blockers. Confirm/cancel/title-bar close share the release callback.
- Explicitly requested updates explain pending editors, confirmations, deletion, media inspection, transfers, other installers and storage failures. Completing deletion, closing a confirmation or finishing a worker retries admission immediately.
- Automatic checks wait thirty seconds after startup and run at most every twelve hours, remembering check times across restarts and failures. Found versions remain visible in the title bar after restart. Only the version hint is cached; clicking it rechecks GitHub before downloading.
- Automatic checking never authorizes downloading or installing. Clicking Upgrade starts download, digest verification and installation when idle; a failed requested update has a title-bar retry action. Settings retain manual checking, opt-out and release notes.

## Verification

- Rust 1.100.0 workspace: **199 passed**, including local audited FFmpeg media integration. Explicit real HTTP/public GitHub smoke and the two subprocess fixture entry points were excluded from this run.
- Extension: **67 passed**; source and manifest remain at companion version 1.1.1.
- New tests cover notice expiry, replacement/dismissal, persistent check cadence, explicit installation intent and cached-version validation. The preference round-trip test also checks persisted discovery/check time and compatibility with older files.
- Clippy passed with warnings denied for all targets. Formatting and whitespace checks passed.
- Installer lifecycle fixtures with the 0.1.3 native host passed launch, guard handling, registered custom-path shutdown, replacement, data preservation and uninstall in isolated temporary profiles.
- Installer and both executable product metadata are 0.1.3. The companion ZIP passed CRC verification and all fourteen files matched source byte for byte.

No native app or browser UI automation was used; visual acceptance remains with the user. The user's live installation and task data were not modified by these checks.
