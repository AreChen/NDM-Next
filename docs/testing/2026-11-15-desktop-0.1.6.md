# Desktop 0.1.6 verification

## Scope and root cause

A user-reported HLS playlist contained 178 segments. Requests and playlist parsing succeeded, but the engine's default 128-descriptor queue rejected the whole snapshot with `QueueLimit` before fetching its first segment. Production now admits up to 16,384 descriptors with a 16 MiB metadata ceiling; the existing 64 MiB download-byte budget and four fetch workers are retained.

Inline media controls left their `notice` class set permanently after a send. Success now briefly shows a compact confirmation and resets after 1.2 seconds; failures reset after four seconds. Player removal cancels the timer, and a late response cannot restore a removed control. Popup feedback also expires.

Companion extension 1.1.3 adds a separate media library, with decoded filename/source search, format filters, selection and batch handoff. Windows stay bound to their source tab, reuse existing resource windows, and clear stale selections on navigation or tab closure. The window sends only captured opaque IDs; replay credentials remain in the background script. Known video/audio extensions served with generic MIME types are also detected. Ordinary HTML and arbitrary binary files are excluded.

New desktop progress windows explicitly call the same GPUI activation operation already used when reopening an existing progress window. This requests foreground activation without setting always-on-top.

## Verification

- Rust 1.100.0 workspace: **207 passed**, including native TS/fMP4/AES HLS, audited FFmpeg integrations, pause/recovery and static DASH. Public-network smoke tests and subprocess fixture entry points are excluded from this count.
- A 3,600-segment synthetic playlist is accepted by production engine options without downloading media. This regression failed with `QueueLimit` before the fix.
- A local 129-segment fMP4 fixture downloads and merges into an MP4 with a video track. It exceeds the previous admission limit and includes discontinuity epochs.
- Extension: **79 passed**, including transient notices, multilingual search, filtered selection, batch failures, source-tab binding, sender authorization, navigation and closure.
- Formatting and all-target clippy with warnings denied passed. Desktop/host tests passed again after the version bump.
- Release compilation and third-party license checks passed. Installer and both executable product versions are **0.1.6**. All **18** companion ZIP files match source bytes; the extension manifest is **1.1.3**.
- Isolated installer lifecycle fixtures passed launch, guard handling, registered custom-path shutdown, replacement, data preservation and uninstall.

The reported site's request and playlist metadata were inspected without playing or fully downloading its video. Its complete transfer and final media output remain unverified. No native-app or browser UI automation was used, and the live installation and tasks were not modified. Visual layout and real Windows foreground behavior remain for manual acceptance.
