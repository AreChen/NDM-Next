# Desktop 0.2.2 validation

## Local checks

- Rust 1.100.0, Windows x64: default workspace tests **225 passed / 15 ignored**, no failures. Ignored media-tool/network/subprocess cases are not counted as verified.
- Browser extension: **79 passed**. Workspace Clippy with `-D warnings`, formatting and Git whitespace checks pass. DESIGN.md lint reports **0 errors / 0 warnings**.
- Search placeholder is selected from the saved language at startup and updated by the language-switch handler. Kit's `set_placeholder` only changes the placeholder, leaving the input value intact.
- Delete confirmation removes explanatory text, reserves a non-shrinking 28px button row and consistent vertical padding. The window is 156px high with a filename, 132px without one. These are source/layout constraints, not a claim of visual acceptance.

## Visual acceptance

The user performs visual review. No browser/computer automation operates the user's application windows. Actual dialog spacing and platform scaling still need user review.

## Release checks

GitHub Actions must build Windows x64 and macOS arm64/x64, validate licenses, and pass default workspace and extension tests before publishing. Public files are checked against GitHub digests and CI artifacts after publication. The opt-in updater check downloads and verifies the installer without executing it.
