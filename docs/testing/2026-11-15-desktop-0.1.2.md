# Desktop 0.1.2 validation

## Changes

- Media requests with Range/If-Range can be replayed as complete resources. Normal download replay remains strict. Popup failures are visible, and buttons recover after failures.
- Optional localized buttons beside webpage media show reliable full-resource sizes and send only previously observed media. Tab, frame and document checks prevent cross-document handoff. Ambiguous blob players remain available through the popup.
- Completed unknown-length downloads show completion and actual output size. The stored server-length verification result remains unchanged.
- Paused progress, segments, active elapsed time and received bytes are saved with task records. Reopening a paused window restores its bytes and percentage; older HTTP/FTP/SFTP partials can supply byte counts without inventing historical timing.
- Compact progress windows show elapsed time and average received-byte speed. Pauses and queue time are excluded; local merge/finalization time is included.

## Verification

- Rust 1.100.0 workspace: **194 passed**, including audited local FFmpeg HLS/DASH integration. Four separately controlled cases were excluded: explicit real HTTP smoke, public GitHub update smoke and the two subprocess fixture entry points.
- Extension: **67 tests passed**, including media range replay, total-length validation, sender and iframe-document isolation, page-control lifecycle, domain/disable behavior and popup feedback. Worker restart, stable IDs, fresh credentials, expiration, navigation during restoration and coalesced session writes are covered. Media replay data stays in trusted, memory-only session storage, bounded to 30 minutes, 50 entries per tab and 500 entries / 4 MiB overall.
- Clippy with warnings denied passed for the workspace and all targets.
- Formatting and whitespace checks passed.
- Installer lifecycle fixtures passed launch, replacement guard, registered custom-path shutdown, replacement, data preservation and uninstall in independent temporary profiles.
- Companion ZIP: 14 entries, CRC check passed, extension manifest 1.1.1 at the root, both new content-script files present.

Independent source review found two additional regressions before release. Failing local-server tests reproduced an offline resume overwriting saved bytes, and received data waiting on the rate limiter being omitted from average speed. The scheduler now recovers remaining owned parts before saving an empty attempt; all five protocol readers count received chunks before cancellable rate-limit/write operations. Both tests pass in the final workspace run.

## Coverage boundaries

No browser or native computer automation was used. Visual acceptance remains with the user. Page buttons cover ordinary video/audio elements; page-owned shadow roots and fullscreen players use the extension popup. Blob matching is intentionally limited to an unambiguous single player and single manifest in its frame. Historical timing from older versions is unavailable and displays as a dash.
