# Desktop 0.1.5 verification

## Scope and root cause

Windows classified the title-bar Upgrade button as a native caption drag area. GPUI's title-bar parent registered `WindowControlArea::Drag`, and its ordinary Button left that ancestor in the native hit-test ID list. This prevented the click from reaching the updater. Settings uses the same update handler outside the title bar and remained usable.

The title-bar action now fully occludes the ancestor hitbox and stops caption mouse-down/up propagation. Its wrapper fits the button; the surrounding title-bar background remains draggable. The update download, verification and installation handlers are unchanged.

## Verification

- Added a headless GPUI regression that registers a native Drag hitbox beneath the production action wrapper. Before the fix it failed because the action retained that hitbox in the full native hit-test list. After the fix it verifies exclusion, one delivered Button click, and retained dragging on the neighboring background. It creates no OS window. GPUI test support is a development dependency only.
- Rust 1.100.0 workspace: **205 passed**, including audited FFmpeg integrations and the new hit-test regression. Public-network smoke tests and subprocess fixture entry points are excluded from this local count.
- Extension: **70 passed**; its code and version **1.1.2** are unchanged.
- Formatting and all-target clippy with warnings denied passed.
- Release build and third-party license checks passed. Installer and both application executable product versions are **0.1.5**. All fourteen companion ZIP files match their source bytes.
- Isolated installer lifecycle fixtures passed launch, guard handling, registered custom-path shutdown, replacement, data preservation and uninstall.

No native-app or browser UI automation was used. The live installation and its download tasks were not changed. Visual acceptance remains with the user. Existing 0.1.4 installations should upgrade through **Settings → About & updates** or the downloaded installer to receive the title-bar fix.
